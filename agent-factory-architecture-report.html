1设计哲学

工厂不是一条写死的流水线,而是一个会自己判断的工程师大脑(像 Claude Code / Codex)。系统给它工具箱和几条硬原则,但"用哪个、用不用、什么顺序"由它自己决定。三条贯穿全局的原则:

本体接地 Grounding
事件名 / 动作名 / 字段名 / 工具名都以业务域本体为准,绝不脑补——这是工厂避免幻觉的根。
端口解耦 Ports
大脑只依赖 7 个接口;具体基础设施(本体源/部署/存储)按运行时注入,所以同一个大脑能在任何环境跑。
验收闸门 Acceptance gate
finish 必须满足「覆盖全 + 每个 agent 有码 + 沙箱真跑到成功终态」——指纹绑定,改了就失效。
新架构相比老仓库的三个根本差异,决定了"不是逐行搬、而是按新原语重写":① 新 llm-gateway.chat() 非流式 → 包内保留 OpenAI SDK 直连做 token 流;② 部署从「动态 createFunction」变成「写 manifest → commit → reregister」;③ 存储从 Prisma/Postgres + Neo4j → Drizzle/SQLite + 文件本体。

2分层技术架构

三层 + 一条端口边界。纯逻辑包不碰任何基础设施;apps/api 是组合根(实现端口、跑后台 run、暴露 SSE);apps/web 是纯 UI,经非缓冲代理消费 SSE。

关键点:包永远不 import apps/* 或基础设施。它声明 FactoryPorts 接口,apps/api/services/agent-factory/index.ts 的 makeFactoryPorts() 是唯一把接口接到 Drizzle / models/ / Inngest 的地方。换数据库、换本体源、换部署方式,只动这一个文件。

3大脑:流式 ReAct 主循环

conductor.ts 的 runBrain() 是一个 async generator:每一轮把消息发给 LLM,token 级流式吐出"思考",模型决定调哪个工具,执行工具、观察结果、进下一轮,直到 finish 通过或预算耗尽。

收敛 & 鲁棒
MAX_TURNS=200 是唯一硬闸(无 token 上限,用户拍板);streamTurn 5 次重试 + 指数退避;402 自适应降 max_tokens;断连=signal abort。
自动压缩
消息超 40 条时把早期对话折成结构化状态快照(specs/plan/sandbox 都在 ctx,不丢信息),不调 LLM。
约束解码
本体已知后,把 design/refine 的 action/tools 参数 enum 约束到真实名,模型发明不出本体里没有的符号。
持久 & 反思
每轮落 BrainCtx 到 factory_conversation(续聊不重来);退出前没写反思就自动补一条(下次更聪明)。

4七个命名角色 — 一支专家团队

大脑在一次构建里分饰七个有名字的专家(在 UI「大脑」tab 的工作循环图里可见),让"每个 agent 角色清晰"。这不是七个进程,而是同一个 ReAct 循环在不同阶段扮演的人设。

9后台 run-registry（断连续跑）

大脑脱离 SSE 请求生命周期跑:在进程内注册表里有一个 detached driver,关掉页面只 unsubscribe,run 继续跑;回来 ?run=<id> 重连(内存没了就从 factory_runs 回放);停止按钮显式 abort。

10沙箱部署:模拟 vs 真 Inngest

两种部署器实现同一个 SandboxDeployer 端口。默认 DryRun 让工厂独立可跑通可 finish;开 FACTORY_REAL_DEPLOY=1 走真 Inngest 注册。

真执行 debug 过两个真 bug:① 函数 trigger 是 ${slug}/${event}(命名空间),发裸事件名不匹配 → ran:0;② runs.triggerEventId 是 events 外键,塞假 id → FOREIGN KEY 失败。修完真跑通。

11测试用例验证闭环（人在环路）

真沙箱前,大脑作为"测试用例设计师"(子大脑)沿事件图造 2-4 个全流程用例(pass reject edge),每个=一条入口事件+真实 payload。conductor 在轮首 park(轮询 mailbox、不耗 turn)等用户点「执行/重新生成」;批准后 sandbox_run 用这些用例真发,「验证」tab 展示逐 agent 真实输入/输出。"喂进沙箱的输入"因此是用户看过、可控的。

14关键设计决策 & 诚实边界

已验证真跑通

DryRun 默认

无 token 上限

剩余
